MATHA TN - VIDEO + QUYEN PREMIUM

1) Thay file HTML hien tai bang MATHA-TN-video-premium.html (co the doi ten thanh index.html neu Vercel dang dung index.html).
2) Trong Firebase Console -> Firestore Database -> Rules: dan noi dung firestore.rules.
3) Trong Firebase Console -> Storage -> Rules: dan noi dung storage.rules.
4) Dam bao Firebase Authentication -> Sign-in method -> Google da duoc Enable.
5) Admin duoc xac dinh bang email: thaigiabao99@gmail.com.
6) Admin dang nhap Google -> vao Quan tri -> quan ly bai hoc -> chon file video -> upload.
7) Hoc vien dang nhap Google. Khi hoc vien xuat hien trong "Quan ly quyen hoc Premium", Admin tick khoa hoc de cap quyen.
8) Video Premium phai upload vao Firebase Storage qua giao dien Admin de duoc bao ve boi Storage Rules. Link Google Drive cu khong co co che bao mat tuong tu.

Luu y: Firebase Storage gioi han kich thuoc upload phia giao dien nay la 1 GB/file. Gioi han thuc te con phu thuoc Firebase plan va cau hinh project.
